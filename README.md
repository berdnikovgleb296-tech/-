 Постановка задачи
 
Датчик технологической установки непрерывно формирует последовательность показаний содержания примеси X (диапазон значений от 0 до 30 %). В программной реализации 60 показаний последовательно считываются из файла. Каждое показание X преобразуется по индивидуальной кусочной функции в индикатор технологического процесса Q: при X < 0 применяется формула 6·√(X-0+1) + 5, при 0 ≤ X ≤ 8 — формула 2·(X-4) + 50, при X > 8 — формула 0.25·(X-8)² + 55.
